# 桌面待办 DeskTodo

Windows 桌面上的轻量待办与工作记录工具，支持项目管理、工作报告和出差报销整理。

使用 PowerShell + WPF 编写，无需安装程序；核心功能不需要额外安装 Python 或 Microsoft Office。

![工作台月视图](screenshot-workbench.png)

## 功能

- **待办与提醒**：输入文字识别时间和项目，例如「明天下午3点 交材料 #年会」；支持具体事项、进展、到期提醒和托盘红点。
- **工作记录**：按日期记录工作，关联项目和待办，可复制到在线表格。
- **工作台与报告**：周视图、月视图，以及日报、周报、月报、季度和年度报告，可导出 Word 文档。
- **报销助手**：导入 PDF / OFD 电子发票，识别金额、日期和行程，整理归档，导出 Excel 台账。
- **OA 填报辅助**：生成可复制的填报内容，由用户粘贴到 OA；不会登录 OA 或自动提交报销。
- **打印整理**：生成 PDF 粘贴单及发票打印文件；OFD 发票需另行打印。
- **多电脑同步**：借助坚果云、百度网盘同步空间、OneDrive 等同步文件夹合并数据。

## 快速开始

### 环境要求

- Windows 10 / 11，使用 Windows 自带的 **Windows PowerShell 5.1**。
- 启动器使用 Windows Script Host（`.vbs`）；若单位设备禁用脚本，请遵循单位的设备管理规定。
- 打开导出的 PDF、Word、Excel 文件需要相应阅读软件；多电脑同步需要自行安装和配置网盘客户端。

### 下载与启动

1. 点击仓库页面 **Code → Download ZIP**，完整解压到固定、可写的位置，例如 `D:\工具\桌面待办`。
2. 打开解压后的文件夹，双击 **DeskTodo.vbs** 启动。不要直接在压缩包里运行。
3. 按 **Ctrl+Alt+N** 呼出或收起窗口。关闭窗口后程序仍驻留托盘；退出请使用托盘菜单。
4. 第一次使用报销功能时，进入「报销 → 设置」填写姓名和默认成本中心 / 部门。

详细操作见 [桌面待办使用说明](桌面待办使用说明.docx)。本文对公开发布、隐私和模板限制的说明作为补充。

## 数据与隐私

程序本身不主动向网络服务器发送数据。默认数据保存在 `%APPDATA%\DeskTodo`；启用网盘同步后，待办、工作记录、项目、报销记录、图片和发票附件会由你选择的网盘软件同步。

- 主要数据文件：`todos.json`、`worklog.json`、`projects.json`、`bills.json`、`expenses.json`。
- 设置和错误日志保存在本机数据目录；打印生成文件位于 `%APPDATA%\DeskTodo\print`。
- 数据主要以普通文件保存，并非加密保险箱；选择同步位置和分享对象前，请检查内容。
- 发布问题反馈时，请先遮盖姓名、发票号码、银行卡、单位内部信息等内容，不要上传真实数据目录。
- 仓库中的 `.gitignore` 用于 Git 提交过滤；**网页手动上传时仍需逐个检查文件，不能依赖它阻止误传**。

## 报销与打印说明

发票识别结果需要人工核对，尤其是金额、日期、入住离店时间和行程。扫描件、图片型 PDF 或特殊版式可能无法识别；当前没有通用 OCR 功能。

`报销单据粘贴单.pdf` 是空白打印模板，程序还内嵌了同一份备用模板。填写位置采用固定坐标：若更换的模板布局不同，需要同步调整脚本中的 `Get-PasteSheetTexts` 等相关坐标。只替换 PDF 不保证对齐。

## 更新与备份

- 更新前先备份数据目录，退出程序后再替换文件，或使用托盘菜单「更新程序（用下载的新版本）…」选择下载的 ZIP / `DeskTodo.ps1`。
- 使用仓库 ZIP 时，也可在文件选择框中手动选择，不必依赖下载文件夹的自动查找。
- 程序通过同步文件夹分发更新时，其他电脑可能自动跟随更新；可在同步设置中关闭自动更新。请只使用你信任且可控的同步文件夹和更新包。
- 下载新版后查看 [更新记录](CHANGELOG.md)，确认需一并替换的说明或模板文件。
